# BS 2.0 — анализ человека по видео: Big Five, эмоции, голос, мимика, речь

Отдельный проект, изолированный от BS 1.0: свой пакет `bs2`, своя команда `bs2`, свой порт (7870), свои рабочие папки
(`~/bs2_data/web_jobs`, `~/bs2_data/pool`, `~/bs2_data/logs`). Общие с 1.0 только тяжёлые ресурсы, которые читаются, но не меняются:
окружение `~/bs/venv`, веса OCEAN-AI в `~/bs/models`, чекпоинты своей модели в `~/bs/mm_runs_seeds`, кэш моделей
Hugging Face и Ollama. Обе версии можно запускать одновременно (1.0 на :7860, 2.0 на :7870).

## Что добавлено к Big Five

| Анализ | Модель / метод | Что выдаёт |
| --- | --- | --- |
| Эмоции по речи | EmoRoBERTa (michellejieli/emotion_text_classifier) по переводу транскрипта | 7 эмоций по каждому отрезку, средний профиль, смены доминирующей эмоции |
| Голос | audeering wav2vec2-large-robust emotion (регрессия) | возбуждение, уверенность (доминантность), позитивность (валентность) 0…1 по отрезкам |
| Мимика | trpakov/vit-face-expression по кропам лица MediaPipe | 7 выражений по отрезкам, движение головы, доля кадров с лицом |
| Речь | транскрипт Whisper с метками времени, без моделей | темп, доля пауз, слова-заполнители, длина фразы, разнообразие словаря, частые слова |
| Big Five | как в 1.0: ансамбль OCEAN-AI + своя модель по сегментам, вариант A для русского | 5 черт, «собеседование», второе мнение, объяснения |

Всё сводится в интерактивные графики (plotly): профиль Big Five (радар), таймлайн черт по ходу ролика, эмоции по
речи и по лицу как доли по времени, голос по отрезкам, темп и паузы; плюс карточки ключевых фактов, пояснение простыми
словами и PDF с теми же графиками.

## Установка и запуск (WSL)

```bash
~/bs/venv/bin/pip install -e bs2-studio
~/bs/venv/bin/pip install plotly                  # графики
bash bs2-studio/scripts/run_web2.sh 7870          # веб: http://localhost:7870 (лог ~/bs2_data/logs/web.log)
~/bs/venv/bin/bs2 infer video.mp4 --lang ru --out result.json   # командная строка (те же команды, что у bs 1.0)
~/bs/venv/bin/python bs2-studio/scripts/selftest.py video.mp4 ru  # полный прогон без веба + PDF
```

Модели эмоций и выражений скачиваются с Hugging Face при первом запуске (около 1.5 ГБ). Первая обработка после
старта сервера включает загрузку всех моделей (около минуты).

## Оговорки

Модели эмоций, голоса и выражений обучены на англоязычных корпусах и фотографиях: их выходы — сигналы о поведении на
видео, относительные и не откалиброванные для русскоязычных людей. Распознавание выражений лица склонно видеть
«грусть» и «страх» в спокойном лице: смотрите на изменения по ходу ролика, а не на абсолютные доли. Big Five —
кажущаяся личность по первому впечатлению; метка «собеседование» — не рекомендация о найме.
