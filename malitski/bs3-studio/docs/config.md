# Настройки BS Profiler 3.1

Все настройки времени выполнения собраны в одном модуле `bs3/settings.py`: папки данных, модели, сервер Ollama,
веб-сервер и нарезка длинных роликов. Модуль использует только стандартную библиотеку, и сам импорт ничего не меняет —
значения читаются один раз, из окружения там, где ниже названа переменная, папки не создаются. Единственная функция с
побочным действием — `apply_process_env()`: она задаёт окружение процесса веб-сервера (см. ниже).

Доменные константы (пороги оценок, палитра, оговорки, словарь, окна анализа, закреплённые идентификаторы моделей) в
`settings.py` не выносятся: они лежат рядом со своей логикой. Их перечень — в конце этого файла.

Ссылка на этот файл — из раздела README «Настройки». Устройство папки задания и `result.json` — в
[result_json.md](result_json.md).

## Переменные окружения

Пять переменных задают настройки напрямую (пустое значение = не задана, берётся значение по умолчанию):

| Переменная | Настройка | Значение |
|---|---|---|
| `BS3_DATA_DIR` | `DATA_DIR` | папка данных (по умолчанию `~/bs3_data`) |
| `BS3_JOURNAL` | `JOURNAL_PATH` | файл журнала (по умолчанию `<DATA_DIR>/logs/journal.txt`) |
| `BS3_OLLAMA_URL` | `OLLAMA_URL` | адрес Ollama, например `http://127.0.0.1:11434` (хвостовой слэш отбрасывается); пусто — автопоиск |
| `BS3_KEEP_FAILED_JOBS` | `KEEP_FAILED_JOBS` | `1` — оставлять папку неудачного анализа для отладки |
| `BS3_KEEP_SEGMENTS` | `KEEP_SEGMENTS` | `1` — оставлять отрезки готового задания для отладки |

`apply_process_env()` дополнительно задаёт для процесса веб-сервера, не перезаписывая уже заданное: `GRADIO_TEMP_DIR`
(= `GRADIO_TMP`), `GRADIO_ANALYTICS_ENABLED=False`, `no_proxy` и `NO_PROXY` (= `NO_PROXY`). Отдельной переменной для пула
обработанных роликов нет: пул из 3.1 убран, `BS3_POOL_DIR` больше не существует.

## Запускающие скрипты и шаблон службы

- **`scripts/run_web3.sh [ПОРТ]`** — запуск веб-сервера в WSL (по умолчанию порт 7880). Создаёт `~/bs3_data/logs` и
  `~/bs3_data/gradio_tmp`, задаёт `GRADIO_TEMP_DIR`, `PYTHONWARNINGS=ignore`, `GRADIO_ANALYTICS_ENABLED=False`,
  `no_proxy`/`NO_PROXY`, при старте удаляет из `gradio_tmp` файлы старше суток и дозаписывает лог в
  `~/bs3_data/logs/web.log`. Остановка — `pkill -f "bin/bs3 we[b]"`.
- **`scripts/run_preview.sh [ПАПКА_ЗАДАНИЯ] [ПОРТ]`** — предпросмотр готового задания на порту 7882 (по умолчанию —
  новейшее задание). Те же переменные окружения; запускает `ui_preview.py` рядом с собой. Остановка —
  `pkill -f "ui_previe[w].py"`.
- **`deploy/bs3-web.service`** — шаблон пользовательской службы systemd (в репозитории только шаблон, он не
  устанавливается и не включается). Задаёт те же `PYTHONWARNINGS`, `GRADIO_ANALYTICS_ENABLED`, `GRADIO_TEMP_DIR`,
  `no_proxy`/`NO_PROXY`, создаёт папки логов и `gradio_tmp` и удаляет из `gradio_tmp` файлы старше суток перед стартом,
  пишет вывод в `web.log`. Включение службы — решение владельца (см. README).

Веб-сервер 3.1 запускается только вручную; автозапуск не включён.

## Параметры анализа: менять только вместе с текстами

`SEGMENT_SEC` (20 с) и `SINGLE_CLIP_MAX_SEC` (30 с) названы словами в шести местах, и число в них должно совпадать с
настройкой (проверяется `tests/test_settings.py::test_segment_lengths_match_the_texts`):

- `pdf/appendix.py` — «по ~20 с»;
- `pdf/sections.py` — «по ~20 с»;
- `pdf/build.py` — «Ролик короче 30 с оценивается целиком»;
- `web.app` — «до ~20 с» (подсказка кнопки «Остановить»);
- `caveats.py` — оговорки C8 и C19.

Меняя длину отрезка или порог «короткого ролика», перепишите эти тексты в том же коммите.

## Доменные константы

Живут рядом со своей логикой, не в `settings.py`. Здесь — где что искать и что затрагивает изменение.

| Что | Где | Значение и смысл |
|---|---|---|
| Полосы уровня оценки | `bs3/scores.py` | `MIDDLE=0.5`, `MID_HALF_WIDTH=0.15` (пограничная зона), `HIGH_DISTANCE=0.30`: пять полос уровня и буквы MBTI считаются от печатного значения (`scores.shown`, два знака). Менять только вместе с формулой заказчика и порогами MBTI |
| Полоса темпа речи | `bs3/scores.py` | `TEMPO_BAND=(100, 160)` слов в минуту — одна на весь проект: и цвет карточки «Темп речи», и слова «медленный / спокойный / быстрый» через один классификатор `scores.tempo_state`. Нижняя граница была открытым вопросом (100 или 110); владелец выбрал 100 (2026-09-27) |
| Состояние эмоции для цвета карточки | `bs3/scores.py` | `EMO_STATE`: какие эмоции и выражения читаются как «спокойнее» / «ярче» нейтральной |
| Минимальная длина ролика | `bs3/media.py` | `MIN_UPLOAD_SEC=2.0` с: более короткий ролик отклоняется сразу — и на странице, и в командной строке (`media.check_upload`); верхнего предела длины и размера нет |
| Пороги слов о речи и движении головы | `bs3/bands.py` | `PAUSE_WORDS=(0.10, 0.25)` (доля пауз), `FILLER_WORDS=(2, 6)` (слов-заполнителей на 100 слов), `HEAD_MOTION_WORDS=(0.05, 0.15)` (сдвиг головы как доля ширины лица). Темпа здесь нет — он в `scores.TEMPO_BAND` |
| Порог уверенности оси MBTI | `bs3/mbti.py` | `CLEAR_CONFIDENCE=0.7`: с этой уверенности ось «отчётливо», ниже — «умеренно» |
| Конфигурация MBTI | `bs3/config/mbti.json` | оси и полюса, `borderline=0.15`, `raw_thresholds` (0.5 по всем осям, формула заказчика), корреляции шкал (`correspondence`), русские названия типов, `min_segments_for_stability=4` |
| Палитра | `bs3/palette.py` | цвета страницы, PDF и «Ключевых фактов»; проверяется `scripts/check_palette.py` (загружает файл отдельно, поэтому модуль без импортов) |
| Оговорки | `bs3/caveats.py` | тексты оговорок страницы и PDF (в том числе C8 и C19 про длину отрезка) |
| Словарь характеристики | `bs3/config/lexicon_ru.json` | формулировки связного текста характеристики |
| Подсказка и разбор фразы кадра | `bs3/frame_phrase.py` | `FRAME_PROMPT`, `PHRASE_MAX=40`, `PHRASE_NUM_PREDICT=48`, `PHRASE_TRIES=2`, `PHRASE_WORDS=(3, 6)`, `PHRASE_BANNED` — ограничения короткой фразы под кадром (тайминги подписей — это `settings.PHRASE_TIMEOUT` и `PHRASE_BUDGET`) |
| Окна анализа AMLAI 1.0 | `bs3/backend_mm.py` (`MMConfig`) | `n_frames=30` — сколько кадров равномерно берётся из клипа |
| Окна анализа OCEAN-AI | `bs3/backend_oceanai.py` (`BackendConfig`) | `window_audio`, `step_audio`, `reduction_fps`, `window_video`, `step_video` — задокументированные окна MuPTA |
| Закреплённые идентификаторы моделей | `bs3/mm/extractors_audio.py` | `whisper-large-v3-turbo` — энкодер аудиопризнаков, с которым обучены чекпоинты AMLAI 1.0. Это не `settings.ASR_MODEL` (распознавание речи) и меняться за ним не должен |
