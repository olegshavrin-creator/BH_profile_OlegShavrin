В папке models содержатся скрипты и файлы классификаторов, инструкции
 какие файлы куда подставлять приложены в каждой папке разбитые по паттернам
отдельно.

В папке Json по нашим видео Приложены все .json файлы
обработанных видео из нашего датасета 5 паттернами.

Библиотеки для Mediapipe pose heavy и mediapipe hands лежат в основной папке, файлы обученных классификаторов если такоевые имеются лежат каждый в своей папке и имеют пояснения в файле readme.md какие и куда подставлять.
